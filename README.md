## 📖 Overview
**Faret El Ahwa (فارت القهوة)** is a fast-paced Lebanese social party game designed for friends, built to be played on a single phone.

Pass the phone around, answer quick challenges in Lebanese Arabic, and try not to be the unlucky person holding it when the coffee finally overflows. As the game progresses, the coffee pot gets hotter, steam starts rising, the phone vibrates more intensely, and the tension keeps building. When the coffee spills... You lose! ☕💥

## 🎮 How to Play
The rules are simple — the chaos is not!

1. Gather your friends and open the game on one phone.
2. Start the round and pass the phone to the first player.
3. Read and answer the Lebanese challenge on the screen.
4. Pass the phone to the next player.
5. Keep going as the coffee pot gets progressively more intense.
6. Watch for the steam, listen to sound effects, and feel the vibrations.
7. Eventually, the coffee overflows.
8. Whoever is holding the phone when it spills loses the round!

## 🛠️ Tech Stack
Faret El Ahwa was intentionally kept lightweight to focus on gameplay and ship fast:

* **HTML5:** Structure and game interface.
* **CSS3:** Responsive UI, animations, RTL layout, and visual effects.
* **JavaScript:** Game logic, challenge system, timers, audio, and haptic controls.
* **Web APIs:** Device vibration and browser capabilities.
* **Offline-First Architecture:** Core gameplay works completely offline.
