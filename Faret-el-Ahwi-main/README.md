# ☕ Qahwa — A Lebanese Social Party Game

> **"Pass the phone, not the blame."**

Qahwa is a fast-paced Lebanese party game where players race to answer local-themed questions before the coffee pot boils over. Add 3–13 players, pass the phone, think fast, and don't be the one holding the *rakweh* when it spills! 🇱🇧

---

## 🎯 The Concept

The rules are simple:

1. A group of friends gathers around **one phone**.
2. The game displays a **Lebanese Arabic challenge** (e.g., *"Name a Lebanese dish"*).
3. The current player answers quickly and **passes the phone**.
4. The countdown timer is **hidden** — no one knows when the round will end.
5. As time passes, the coffee pot boils harder: steam rises, the screen shakes, and vibrations intensify.
6. When the coffee **overflows**, whoever is holding the phone **loses**.

No turns, no waiting, no boredom — just chaos, laughter, and a very tense coffee pot.

## ✨ Features

- 🎮 **3–13 players** — one phone, endless chaos
- 🇱🇧 **60+ Lebanese-themed questions** in local Arabic dialect
- ⏱️ **Hidden countdown timer** — nobody knows when it ends
- ☕ **Dynamic boiling animation** — steam, shaking, and intensity scale with time
- 📳 **Haptic feedback** — vibrations intensify as the pot nears overflow
- 🔊 **Sound effects** via the Web Audio API
- 🌙 **Dark mode** support
- ↔️ **Full RTL support** for Arabic
- 📴 **Fully offline** — installable as a PWA
- 📱 **Mobile-first design** — built for passing around

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18 or higher) — [Download here](https://nodejs.org)
- **A package manager**:
  - **npm** (comes automatically with Node.js )

### Installation

```bash
# Clone the repository
git clone https://github.com/fatima12345676/Faret-el-Ahwi.git
cd Faret-el-Ahwi

# Install dependencies
npm install

```

### Run Locally

```bash
# With npm
npm run build
npm run dev

```

Open the link (example) [http://localhost:5173](http://localhost:5173) the exact port may vary in your browser.
